# Landing page assets

All demo names, relationships and stories are fictional. The family is inspired by
Code Geass and is not affiliated with Sunrise.

## Portraits

Generated with [DiceBear](https://www.dicebear.com/), using the
[Avataaars](https://avataaars.com/) style by [Pablo Stanley](https://twitter.com/pablostanley).
Avataaars is free for personal and commercial use. DiceBear is MIT licensed.

Each portrait uses fixed options so the cast looks consistent. Run
`scripts/landing-assets.sh` to regenerate every portrait and photograph from its
source. The script needs curl and ffmpeg.

## Demo family note

Code Geass names and relationships belong to Sunrise. The `li` and `el` consorts are
not named in the source material, so "Helena li Britannia" and "Elise el Britannia"
are placeholder names created for this demo.
