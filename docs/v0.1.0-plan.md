# v0.1.0 plan

This file tracks the work planned for v0.1.0. Update the checkboxes as work lands.

## Scope

In scope:

- Safety net: automated backups and error tracking.
- Account completeness: email change, account export, account deletion.
- Fuzzy dates for people, partnerships, and photos, plus person events.
- Activity history, realtime refresh nudge, and duplicate person detection.
- Read-only demo tree and public read-only share links.
- README updates and a roadmap for deferred features.

Out of scope for v0.1.0:

- Privacy policy, data retention policy, and GDPR pages (handled in a separate session).
- GEDCOM import and export (roadmap only).
- Printable tree chart export (roadmap only).
- Running more than one replica.
- OCR and face detection.
- Person merge tooling (duplicate detection only).

## Decisions

Locked:

- Public read-only share links are in v0.1.0.
- GEDCOM is deferred and documented in the roadmap.
- Tree poster export is deferred until the graph visuals improve.
- Scaling work is deferred. One replica is enough for now.
- Resend email deliverability is already acceptable.
- The demo tree uses the normal tree UI, is static, and is read-only.

Proposed defaults, confirm during implementation:

- Backups go to an off-site S3-compatible bucket and are encrypted before upload.
- Error tracking uses Sentry with PII scrubbing, or self-hosted GlitchTip if ops time is available.
- Share links default to names only for living people, with media off.
- Fuzzy dates use a JSONB value object and support unknown birth years.
- Events use a fixed kind enum plus `other`.
- The demo renders the static `demo-tree.ts` dataset through the real workspace UI.
- Account deletion is immediate, with password plus typed email confirmation.
- Activity history is kept indefinitely for now, and account deletion anonymizes the actor name.
